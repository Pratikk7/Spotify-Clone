# 🎵 Spotify Clone

A responsive **Spotify Web UI Clone** built using **pure HTML and CSS**.  
This project recreates the look and layout of Spotify’s web player, focusing on frontend design and responsiveness.

---

## 🚀 Features

- Spotify-inspired modern UI
- Sidebar navigation and library section
- Music player layout (UI only)
- Responsive design for different screen sizes
- Clean and structured CSS styling

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox & Responsive Design)

---

## 🎯 Purpose of the Project

This project was created to:
- Practice HTML & CSS fundamentals
- Understand real-world UI layout
- Improve responsive web design skills
- Build a portfolio-ready frontend project

---

## ⚠️ Disclaimer

This is a **UI clone only**.  
No backend, authentication, or real music playback functionality is implemented.
